# Independent Bengali Quran Draft Workflow

This directory is an independently composed Bengali translation and phonetic transliteration draft. It is NOT authoritative, has not been scholar-certified, and must not replace existing licensed QuranEnc pages until qualified human review is complete.

First batch: Al-Fatihah (1:1-1:7) and Al-Baqarah (2:1-2:5), 12 ayahs total. Each record stores Arabic, original Bengali composition, original Bengali phonetic rendering, uncertainty flags, and review state. Other translations and recitations are cross-checks only, never templates.

Only review_status scholar_reviewed may be considered for publication. This batch is unreviewed_draft and publishable=false. Transliteration is a reader aid, not tajwid instruction; madd, ghunnah, qalqalah, assimilation, waqf/ibtida and articulation require expert review.
