## Riddlex Learn From Players checkpoint

On `codex/riddlex-arcade`, the defeat path now admits “I couldn't figure it out this time. Who were you thinking of? Help me learn!”, asks up to two additional distinct questions when fewer than two hard facts are known, and offers an optional mobile form. Submissions retain the current answer history and only Yes/No become hard facts; probable and unknown answers remain uncertain. Authenticated Firebase users get per-account private records. Public knowledge is separate and requires administrator approval. The existing admin portal can review/correct facts, reject, merge duplicates, approve images, and remove published entries. Approved records are merged into the runtime candidate pool and can reach the printer reveal; image-less records use handwriting.

Evidence: `python -m unittest -v test_riddlex_learning.py` reports 8 passed and 1 skipped (image transform skipped because Pillow is unavailable locally); Python compile passes. Mocked Chromium flow previously passed at 390px and 1280px, including ten unanswered prompts to defeat, private submit/reload retrieval and owner deletion, image-rights gate, admin approval, candidate ranking, and photo/handwriting reveal states. Browser page errors: 0; horizontal overflow: false. This is mocked persistence, not a live Firestore test. The browser rerun in this workspace could not start because Playwright is not installed in the website worktree. Render has no `WALID_FIREBASE_SERVICE_ACCOUNT_JSON` available in the repo/deployment configuration at inspection; API endpoints stay 503 until the server secret is configured. Pillow is declared for deployment but package install was blocked by network policy, so EXIF stripping was not executed here.

## Resumption instructions

Start from current `main`, refresh refs, and branch one game at a time. Run its deterministic tests and Chromium checks at 320, 360, 390, 768 and 1280px, inspect captured frames for visual changes, then commit/push/open and integrate only that verified game. Deploy and verify its live URL before moving to the next game. Keep Riddlex on its development branch until its animation, gameplay and data acceptance criteria pass. Update this tracker with commit, tests, production URL and genuine remaining issues after every release.
