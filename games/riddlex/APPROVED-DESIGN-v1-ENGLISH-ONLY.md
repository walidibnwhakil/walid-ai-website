# Riddlex v1 language correction

Approved 2026-11-05. This supersedes the language requirement in
`APPROVED-DESIGN-v1.md`.

Riddlex v1 is English-only. Questions, answers, buttons, menus, and result
names are rendered as English HTML text. Existing translated casebook fields
are retained in the data and are outside the v1 interface.

Lettering in the reference images is placeholder material. The approved A4
detective, B1 cat, C4 office, composition, and motion references continue to
guide the visuals.
