## Game flow and motion

1. Splash: the window scene has subtle live motion and leads into gameplay via Play.
2. Selection: exactly Characters, Animals, Objects. Personal acquaintances, family and relationships belong inside Characters. No separate Someone I Know choice.
3. Questions: English first, using actual DOM text for headings, questions, buttons and result names. Exact answers are Yes, No, Probably, Probably Not, Don't Know. Ask discriminating, nonredundant questions. Exclude birth-year trivia. Unknown answers are neutral evidence. Preserve the existing playable knowledge, data and regressions.
4. Correct with photo: the compact side printer gradually feeds a photo of the confirmed character. The detective picks up that same print and presents it with the character's name.
5. Correct without photo: the detective writes the name on a note and presents it in handwriting-style DOM text. The printer stays idle.
6. Wrong or unresolved: the detective visibly reacts with disappointment, crumples the note and throws it backward into a background or offscreen bin. Keep the front desk free of a visible bin. The annoyed cat lies on a separate desk note and rises on Retry.
7. Animate the transitions and actions in the playable flow. Keep the room, camera, palette and character likeness coherent. Verify splash, selection, questions, both correct branches, wrong, unresolved and Retry in a browser before any release.
