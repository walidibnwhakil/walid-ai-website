Riddlex photo credits

Riddlex plays in the browser. This page lists the photographs and artwork the game actually loads, and the data license recorded for the Wikidata portion of its questions.

Albert Einstein photograph

The only casebook photograph mapped in the game is Albert Einstein. The file is a local 150-pixel copy of a Harris & Ewing photograph, Library of Congress item 2016885961. The Library of Congress catalog record states that there are no known restrictions on publication. The image file the copy was taken from is 31012_150px.jpg. The game shows it only when that case is the guess being revealed.

Scene artwork

The window splash, the seated office, the detective, the cat, and the related pose layers shipped with the game are crops and masks made from artwork supplied for Riddlex. The writing-arm and reaching-arm layers are crops from a pose sheet generated with an image generator, using the seated office picture as the reference for identity, clothing, lighting, and camera. The generated face and torso from that sheet are not composited into the game.

Those supplied source images are not given a separate photographer credit in the game files. This page does not add one.

Question data

Part of the Riddlex question data is compiled from Wikidata. The snapshot used for that portion records the CC0 1.0 license and links each used statement back to Wikidata. Wikidata’s licensing note is at Wikidata:Licensing. Other questions were written for the game. The game screen currently asks the English questions. Bangla question strings are in the data files and are not what the screen shows.
