How to prepare images for the web

Image dimensions, file format, and compression affect upload speed and appearance. These steps help you choose the smallest file that still looks clear.

Resize first when dimensions are the problem

Use Resize Image when a service asks for a particular width or height. Keep the original aspect ratio when possible so faces and logos do not look stretched.

Choose a format

  • JPG is useful for photographs and usually produces small files.
  • PNG preserves sharp edges and transparency.
  • WebP is often compact for websites, but check whether the destination accepts it.

Compress and check

Use Compress Image after resizing. Compare the downloaded file at 100% zoom, especially around text, hair, and thin lines. For multiple format conversions, Convert Image supports JPG, PNG, and WebP.

Backgrounds and transparency

Remove Image Background can create a transparent PNG. A checkerboard preview means transparency, not a gray background. Before publishing, test the image on both a light and dark background.

Privacy note

Many image tasks run in your browser, so the selected image can remain on your device. Read the individual tool’s explanation before using a feature that downloads a processing model or sends data to a service.
