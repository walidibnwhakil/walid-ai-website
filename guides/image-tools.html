How to prepare images for the web

Dimensions, file format, and compression affect upload speed and appearance. A good result is not simply the smallest file: it is the smallest file that still preserves the details people need to see.

Start with the destination

Check the receiving site’s maximum dimensions, file size, and accepted formats first. Keep the original in a separate folder. Resize only the copy, and keep its aspect ratio unless the destination explicitly requires a crop.

Choose a format

  • JPG: usually best for photographs and gradients.
  • PNG: useful for transparency, screenshots, and sharp graphics.
  • WebP: often compact for websites, but verify that the destination accepts it.

A practical workflow

  1. Use Resize Image when the width or height is the problem.
  2. Use Convert Image when the format is not accepted.
  3. Use Compress Image after resizing, not before.
  4. Open the downloaded file at 100% zoom and compare text, faces, hair, thin lines, and edges with the original.

Backgrounds and transparency

Remove Image Background can create a transparent PNG. A checkerboard preview means transparency, not a gray background. Test the result on both light and dark backgrounds; hair, shadows, and small objects often need a closer check.

Common problems

  • Blurry text: start from a higher-resolution original and avoid repeated JPG saves.
  • Huge file: resize first, then compress once.
  • Unexpected background: confirm whether the output is transparent PNG or a flattened image.
  • Wrong colors: compare the file in the destination app, because color handling can differ between viewers.

Privacy note

Many image tasks run in your browser, so the selected image can remain on your device. Read each tool’s processing note before using a feature that downloads a model or sends data to a service. Do not upload private photos or documents unless you understand that path.
