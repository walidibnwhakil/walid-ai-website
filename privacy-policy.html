Draft for owner review. This draft describes behavior found in the reviewed source. Production retention, host logging, and third-party provider practices are not fully verified.

Walid AI is operated by Whakil Ahamed Shakil, an individual developer in Bangladesh. This draft explains data handling visible in the current website and backend source; it does not make claims about provider practices that have not been verified.

Information and storage

  • When you sign in, the website uses Firebase Authentication. Signed-in chat records are saved in Firebase Firestore under the account’s user record. The interface supports deleting individual saved chats. The reviewed code does not provide an account-wide deletion flow.
  • Guest chat records are kept in browser session storage. The code does not promise a server-side guest chat history.
  • The browser also stores certain settings and interaction data, including the selected language, liked-answer selections, a guest identifier, and sign-in flow values, using local or session storage.
  • The backend can save information that a user has asked it to remember in files in its configured data directory. The reviewed code does not show a user-facing deletion control for those saved memories. The actual production data directory, backup behavior, and retention are not confirmed here.
  • The backend also keeps usage counters and hashed identity keys for daily quota accounting. This is usage data, not a complete record of chat text.

AI requests and files

Chat messages and selected attachments are sent by the website to the Walid AI backend hosted on Render. The reviewed frontend encodes attachments as Base64 data in the request. Chat accepts up to five attachments, with a limit of 5 MB per file and 15 MB combined. The reviewed backend extracts text from PDF files (up to the first 12 pages), DOCX, TXT, MD, and CSV files. Image attachments may be forwarded to Google's Gemini API, and extracted document text may be included in a Gemini request to prepare a response.

No persistent write of chat attachment files was identified in the inspected backend handlers. This does not establish that request bodies are never present in runtime memory, logs, diagnostics, backups, or third-party systems. Exact Render logging/runtime retention and Google's handling and retention for this project have not been verified. Avoid sending files or information you do not want processed by these services.

Google's current Gemini API Additional Terms distinguish unpaid-quota use from paid API use. For unpaid services, Google may use submitted content and outputs to provide, improve, and develop its services and may have them reviewed by people; for paid services, prompts and responses are not used to improve Google products, while limited safety, security, and legal logging may still occur. These terms also state that the API is for professional or business use, not consumer use, and require API users to be at least 18; API clients must not be directed to or likely accessed by people under 18. Walid AI's current project billing mode, audience, and age controls have not been verified, so this policy does not claim that either service category or those conditions describe the live configuration.

Some PDF, image, and ZIP tools process files in the browser; the background-removal tool loads Transformers.js and the MODNet model from external hosts. Tool-specific processing may differ from chat attachment processing. The model revision and all production-delivered tool assets have not been fully inventoried.

Cookies, analytics, and advertising

The reviewed website source does not explicitly create a first-party analytics cookie or include a Google Analytics tag. It loads Firebase authentication and Google Identity scripts. Google AdSense code is present, but ad rendering is conditional on a configured ad slot; the reviewed ad configuration has no populated slots. Storage or cookies used by Google or Firebase, and the current production ad configuration, have not been independently verified.

Retention, deletion, and security

Saved signed-in chats can be deleted individually through the interface. Guest chat data is stored in session storage. No account-wide deletion mechanism or fixed retention period was found in the reviewed source. Backend file retention, backups, hosting logs, and provider-side retention are not confirmed. The project review alone cannot verify security controls or guarantee deletion from backups or third-party systems.

Your choices and contact

You can avoid signing in, avoid submitting sensitive information, and delete individual saved chats where that control is available. For privacy questions or requests, contact support@walid-ai.com. The owner reports that this Zoho Mail Free address has been tested for sending and receiving.
