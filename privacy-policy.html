Privacy Policy

Effective November 7, 2026. This policy describes Walid AI at https://walid-ai.com/. A Bangla version is at গোপনীয়তা নীতি.

Walid AI is operated by Whakil Ahamed Shakil, an individual developer in Bangladesh. Privacy questions can be sent to support@walid-ai.com.

What this policy is based on

This policy describes what the public website code does. The chat and PDF API address configured in the site is https://walid-ai-backend.onrender.com, on Render. Sign-in and saved chats use Google Firebase. The website does not include the backend program, so this policy does not state Render log retention, backup retention, or Google’s retention for this project. Where that limit matters, the policy says so.

Information the site handles

  • Chat text. When you send a question, the page posts it to /api/chat on the Render backend, together with a guest identifier stored in this browser.
  • Account. Sign-in uses Firebase Authentication. Google sign-in is implemented with a Google account popup. The page can also ask Firebase to email a sign-in link. The address you type for that link is stored in this browser’s local storage until you open the link. Whether email-link sign-in is enabled in the Firebase project is controlled by Firebase, not by a switch in this page.
  • Saved chats. If you are signed in, chat text is saved in Cloud Firestore under your user id, in a chats collection. Each saved record has an id, a short title, the message text, a source label when the interface has one, and an updated time. You can delete one saved chat from the chat list. The website has no button that deletes the Firebase account or every chat at once.
  • Guest chats. If you are not signed in, chat text is kept in this browser’s session storage, up to 50 conversations. It is removed when that browser session ends and when you use Log out. It is not written to Firestore.
  • Files and photos in chat. Sign-in is required before you can attach files, unless the operator admin session is in use. You can attach up to 5 files to one message, and each file must be 5 MB or smaller. The photo picker accepts PNG, JPEG, WebP, and GIF. The file picker accepts PDF, DOCX, TXT, MD, and CSV. The page then checks the type reported by the browser and refuses a file that does not match those types. The file name, reported type, and file bytes are sent to the backend as Base64 in the chat request. The saved chat record stores the question and answer text, not those file bytes.
  • Upload count. Before a file is added, the page asks the backend /api/upload-quota how many uploads remain today. The number is returned by the backend. This website file does not contain that daily number. The interface can show that an admin session has no upload limit.
  • Guest identifier and settings. The page stores a random guest id, your English or Bangla language choice, up to 100 liked-answer texts, the active chat id, and, during email-link sign-in, the email address you entered. Language, guest id, liked answers, and the signed-in active chat id use local storage. Guest chats and the guest active-chat id use session storage.
  • Personal memory label. If the backend says an answer was saved as a personal memory, the chat labels it that way. This website does not show a list of those memories or a delete control for them, and it does not show where the backend keeps them.
  • Help and contact. The Help form and the contact page open your own email app addressed to support@walid-ai.com. They do not submit the message to the Walid AI server. A separate operator admin page says that help reports shown there, and an optional reply email, are kept for up to 30 days. The public form does not send messages into that inbox.

AI requests

The chat page does not call Google’s Gemini API itself. It sends the question, guest id, and any attachments to the Walid AI backend. The operator admin view counts those backend calls as Gemini API requests, so chat is built to be answered with Gemini. The website does not include the Gemini API key, the model name, or whether that Google project is billed.

Google’s Gemini API terms describe different handling for unpaid and paid use, and they describe the API as a professional or business service for users who are at least 18. This website does not show which of those categories applies, and it does not ask your age. Do not send information you do not want processed by Walid AI’s backend and by Google’s Gemini API. This policy cannot state how long Google keeps that content.

The chat can label an answer as coming from your file or from a PDF, and it can say that setup or OCR is required or that no readable text was found. Those labels show that the backend may read an uploaded file to answer. They do not show a page limit, an OCR language, or that the backend saves the file. No chat-attachment file write appears in this website code.

PDF, image, and ZIP tools

  • PDF tools. Merge PDF, Split PDF, Compress PDF, and PDF to Word send the PDF bytes to the same Render backend. On the public tool pages the request goes to /api/tools/ and does not include your Firebase token. A PDF action started inside chat can go to /api/chat-tool/ with the sign-in token. The page refuses a batch larger than 20 MB. Merge needs at least two PDFs. The other PDF tools use one PDF. The backend returns a file, and the browser downloads it. Split PDF draws page previews in the browser with PDF.js 4.10.38 loaded from jsDelivr, for up to the first 100 pages. The split itself is done by the backend from the page list you enter, such as 1-3,5. This website does not show the backend saving those PDFs in your account.
  • Image tools that stay on the device. Resize, compress, convert, signature-background removal, and watermark removal run in the browser. Resize accepts a width and height from 1 to 10,000 pixels. Compress and convert output JPG, PNG, or WebP, with a quality setting from 20 to 100, and convert handles up to 10 images at a time. JPG output is drawn on white, so transparency is not kept. The signature tool clears a paper color connected to the edges of the picture. The watermark tool fills a selected area from nearby pixels and rejects an area larger than 45 percent of the width or height. These tools do not upload the image to the Walid AI backend.
  • Background remover. The image is processed in the browser. The page loads Transformers.js 3.8.1 from esm.sh and a model named Xenova/modnet. The working copy is scaled so the longest side is at most 2,048 pixels, and the download is a transparent PNG. The image is not sent to the Walid AI backend by this page. The model file is downloaded from the host that library uses. The page does not pin a model revision.
  • ZIP. Create ZIP and Extract ZIP run in the browser with fflate 0.8.3, loaded from jsDelivr. Your files are not sent to the Walid AI backend. The page has no fixed size cap; a very large archive depends on the browser’s memory. Create ZIP flattens slashes in file names.

Games

The games run in the browser. Riddlex, chess, Football Penalty, and tic-tac-toe do not write a score to storage. Riddlex loads its question files from this website and does not send your answers to the chat backend. Its screen states that no personal information is collected. Snake stores the best score in local storage under walid-snake-best. 2048 stores the best score under walid-ai-2048-best. Ludu Mahir stores the current setup — player count, mode, colors, and sound — in session storage under ludu-mahir-game. Games do not require an account.

Cookies, local storage, and advertising

The website’s own scripts do not set a first-party analytics cookie, and the pages do not include a Google Analytics tag. They do use local storage and session storage, as described above. Those stores stay on your device until you clear them, the session ends, or the page removes them.

The chat page loads Firebase and Google Identity Services. Those Google scripts may store identifiers in cookies or similar browser storage to keep you signed in. Cookie names are chosen by those providers.

Walid AI has applied to use Google AdSense, publisher ca-pub-7143554641494116. The site’s ads.txt file authorizes google.com for that publisher. Ad slot ids in the site configuration are empty, so the tool and chat pages do not render an ad unit until a slot id is added. The homepage includes Google’s AdSense site snippet for that publisher. That snippet loads https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js. When that script runs, Google can store and read cookies and use data from the browser to provide and measure ads, including ads that are personalized, as Google describes for sites that use its services.

Google explains that use here: How Google uses information from sites or apps that use its services and Advertising. You can control personalized ads at Google Ad Settings. You can also use the Digital Advertising Alliance opt-out at optout.aboutads.info. Those controls are Google’s, not a switch inside Walid AI.

This website does not show a cookie-consent banner. Google requires a Google-certified consent management platform before personalized ads are served to people in the EEA, the UK, or Switzerland. That banner is not part of the site today.

Retention, deletion, and security

Signed-in chats stay in Firestore until you delete that chat or the data is removed from Firebase. Guest chats stay only for the browser session, and Log out clears them. Liked answers, the guest id, and the language choice stay in local storage until you clear site data. There is no fixed retention period in this website for backend request logs, Render disks, or Google’s copies of prompts.

To ask for deletion of chat data tied to your sign-in, email support@walid-ai.com from the address you can access, and say which Google account you used. The website cannot confirm deletion from provider backups or from Google’s systems.

Chat requests send a Firebase ID token, or an operator admin token, in the Authorization header when one is available. Public PDF tool pages do not send that token. The admin token, when used, is kept in session storage. The website cannot audit Firebase, Google, or Render security controls.

Children

Walid AI is a general-audience site. It is not directed to children, it does not ask for a date of birth, and it does not offer a child account. Do not submit a child’s personal information in chat or in a file.
