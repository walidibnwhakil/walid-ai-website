Remove Background

Remove a photo background and download a transparent PNG.

Sponsored

How to remove a background

Select one PNG, JPEG, or WebP photo. Press Remove Background. The first run downloads the removal model, which can take a moment. When it finishes, download the transparent PNG. Open it on a checkerboard or in an editor to see the transparency. A plain image viewer may show the empty area as black or white.

Formats and limits

  • One PNG, JPEG, or WebP image.
  • The download is a PNG at the photo’s original width and height. Photos above 16 megapixels are matted on a 16-megapixel working copy, then drawn back at the original size.
  • The download is PNG. This tool does not output JPG, because JPG cannot store transparency.
  • Checkerboard preview is optional and is not saved into the file.

Where the file is processed

The photo stays in your browser. It is not uploaded to the Walid AI backend. The page loads Transformers.js 4.3.2 from jsDelivr and runs it with ONNX Runtime Web. When the GPU supports 16-bit shaders, it uses the MIT-licensed model wonfy/BiRefNet_lite-ONNX-webgpu, revision c40eaa22fb1af9edcf75c7b79d25ed8a8e901140, a 1,024-pixel BiRefNet lite export with fp16 weights. If those shaders are missing, or the 1,024 model does not start, it uses studioludens/birefnet-lite-512, revision 962e67969ec6acec9c19fab76acee4f5e22e990c, on WASM. That fallback uses fp16 weights when WASM can run them and fp32 weights when it cannot. The 512 model also runs on WebGPU when 16-bit shaders exist but the 1,024 model failed. Both are MIT-licensed exports of ZhengPeng7/BiRefNet_lite. Model files download from Hugging Face. RMBG-1.4 is not used: those weights are non-commercial, and this site is set up for advertising.

Troubleshooting

  • If it stays on “Downloading the background model…”, Hugging Face or jsDelivr may be blocked or slow. Retry on a connection that can reach both.
  • Hair, glass, and a background that matches the subject can still be cut too tightly or left behind. The page has no brush to fix the mask. Turn on checkerboard preview to judge the edge.
  • For a signature on paper, use Remove Signature Background instead. That tool does not download a model.

Short FAQ

Do I need an account? No.

Is the photo sent to an AI server? Not to the Walid AI backend. The model weights are downloaded so the removal can run locally in the page.
