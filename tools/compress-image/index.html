How to compress an image

  1. Choose a JPG, PNG, or WebP image.
  2. Select JPG or WebP and adjust quality.
  3. Continue, check the resulting size, and download.

Quality and format

Lower quality usually reduces file size but can add visible artifacts. JPG does not preserve transparency. The best settings depend on the image and how it will be used.
