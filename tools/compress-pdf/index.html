Compress a PDF Online

Process a PDF to reduce redundant objects and file size where possible. The amount of reduction depends on how the original document was created; a processed PDF can sometimes stay the same size or become slightly larger.

How to compress a PDF

  1. Choose one PDF file, up to 20 MB.
  2. Run Compress PDF.
  3. Download the result and compare its size with the original.

What to expect

This tool reorganizes PDF content; it does not lower image resolution. Image-heavy PDFs may see little change. Keep the original if you need a guaranteed smaller output.
