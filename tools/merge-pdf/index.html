How to merge PDFs

  1. Choose at least two PDF files.
  2. Select them in the order you want to combine.
  3. Run Merge PDF and download the resulting file.

File requirements

The combined upload must be 20 MB or less. The files are processed for the merge and are not kept as a permanent copy. Review the output before sharing it.
