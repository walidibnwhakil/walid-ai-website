Merge PDF

Combine PDFs in your preferred order.

Sponsored

How to merge PDFs

Select at least two PDF files, or drop them on the tool. Each file is listed with its size. Use the up and down controls to set the order. The first file’s pages come first. Press Merge PDF and download the file when it is ready. The download name starts with “Walid AI_”.

Formats and limits

  • PDF files only. Other formats are refused.
  • At least two PDFs. One file is not a merge.
  • The combined size must be under 20 MB. Larger batches stop with an error before upload.

Where the file is processed

The PDFs are sent to the Walid AI backend, which returns the merged file to this browser. The public tool page does not send your sign-in token and does not save the PDF in a Walid AI account. Page order is chosen here; the merge runs on the server.

Troubleshooting

  • If nothing happens, check that two or more files are selected and that the total is under 20 MB.
  • A password-protected or damaged PDF can fail. The page shows the error returned by the server, or a generic message if there is none.
  • The request needs a network connection to walid-ai-backend.onrender.com. A blocked network or a sleeping free-tier server can delay or fail the first request.

Short FAQ

Can I rearrange pages inside one PDF here? No. This page joins whole files. To keep only some pages, use Split PDF first.

Does merge need an account? No. Sign-in on this page is optional.
