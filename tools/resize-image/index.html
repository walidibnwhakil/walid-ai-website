How to resize an image

  1. Choose a JPG, PNG, or WebP image.
  2. Enter the output width and height in pixels.
  3. Continue and save the resized image.

Keep the proportions in mind

Entering dimensions with a different aspect ratio can stretch or compress the image. Use matching proportions when you want to preserve its shape. The current size limit is 10,000 pixels per side.
