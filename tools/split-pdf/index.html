How to split a PDF

  1. Select one PDF file.
  2. Enter pages such as 1-3,5 to keep pages 1 through 3 and page 5.
  3. Continue and download the new PDF.

Before you start

Page numbers begin at 1 and must exist in the document. The file limit is 20 MB. Check the resulting pages before sending the file to anyone.
