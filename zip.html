    How to create a ZIP

    Open Create ZIP, select one or more files, or drop them on the box. Press Create ZIP. The browser builds the archive and downloads it. Slashes in file names are replaced, so folders in the selection are stored as flat names.

    How to extract a ZIP

    Open Extract ZIP, select one .zip file, and press Extract ZIP. Each file inside gets a download link. Empty archives, and archives that contain only folders, show an error. The download name starts with “Walid AI_”.

    Formats and limits

    • Create accepts the files you select. Extract expects a ZIP archive.
    • The page does not set a maximum size. A very large archive depends on this browser’s memory and may fail or stall.
    • The ZIP library is fflate 0.8.3, loaded from jsDelivr. If that script does not load, the page asks you to check the connection and try again.

    Where the file is processed

    Create and extract run entirely in your browser. The files are not sent to the Walid AI backend. Only the fflate program is downloaded from jsDelivr.

    Troubleshooting

    • “ZIP library could not load” means the page could not reach jsDelivr.
    • “This ZIP archive contains no files” means the archive had no file entries.
    • Password-protected ZIP files are not supported. The page has no password field.

    Short FAQ

    Do I need an account? No.

    Can I extract a RAR or 7z file? No. This page reads ZIP archives.
